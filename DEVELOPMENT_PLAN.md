## Этап 12: Разделение app.py (критический этап)
**Цель:** Разделить монолит на слои: контроллеры / состояние / UI
**Срок:** 2-3 недели
**Риск:** Временное замедление, но без этого Этап 13 невозможен

### Задачи:
1. **Создать `astro_core/controllers/`** — чистая логика операций без Streamlit:
   - `chart_controller.py` — расчёт натальной карты
   - `transit_controller.py` — транзиты (3 режима)
   - `progression_controller.py` — прогрессии
   - `profile_controller.py` — профили рождения
   - `display_profile_controller.py` — профили отображения
   - `city_controller.py` — города и таймзоны

2. **Создать `astro_core/state/`** — управление состоянием сессии:
   - `session_state.py` — единая модель данных (Pydantic/dataclass)
   - `settings_manager.py` — загрузка/сохранение настроек

3. **Создать `ui_streamlit/`** — тонкий слой отображения:
   - `components/` — переиспользуемые виджеты
   - `pages/` — вкладки (chart, transits, progressions)
   - `app_streamlit.py` — новая точка входа

4. **Критерий готовности:** Старый `app.py` работает как раньше; контроллеры импортируются и тестируются без Streamlit.

## Этап 13: Интерфейс на PyQt6 (главный этап)
**Цель:** Полноценное настольное приложение (окно, иконка, меню, ярлык)
**Срок:** 4-6 недель
**Риск:** Самый объёмный этап; два интерфейса параллельно

### Архитектура PyQt:
```
ui_qt/
├── main_window.py          # QMainWindow, меню, тулбары, статусбар
├── widgets/
│   ├── birth_input_panel.py
│   ├── chart_view.py       # QGraphicsView + SVG рендеринг
│   ├── transit_panel.py
│   ├── progression_panel.py
│   ├── profile_manager.py
│   ├── display_profile_editor.py
│   └── city_selector.py
├── models/
│   └── chart_model.py      # QAbstractTableModel для таблиц
├── dialogs/
│   └── settings_dialog.py
└── app_qt.py               # Точка входа, QApplication
```

### Ключевые решения:
- **SVG рендеринг:** Использовать `QSvgRenderer` + `QGraphicsScene` (поддержка зума/панорамирования нативно)
- **Цвета/орбы:** Переиспользовать `display_profiles.py` без изменений
- **Правило стабилизации:** На время Этапа 13 **нет новых функций** — только паритет со Streamlit
- **Паритет:** Все функции Streamlit-версии должны работать в PyQt

### Этапы реализации:
1. **Неделя 1:** Каркас (MainWindow, меню, навигация, тема)
2. **Неделя 2:** Панель ввода рождения + города + таймзоны
3. **Неделя 3:** Графическая карта (SVG в QGraphicsView, зум/панорамирование)
4. **Неделя 4:** Транзиты (3 режима, фильтры, таблицы)
5. **Неделя 5:** Прогрессии + профили рождения
6. **Неделя 6:** Профили отображения (редактор), полировка, багфиксы

## Этап 14: Упаковка и установщик
**Цель:** Установщик для Windows (мамин компьютер без Python)
**Срок:** 1-2 недели
**Риск:** Пути к данным в frozen-сборке, антивирусы, размер

### Задачи:
1. **Единый модуль путей** (`astro_core/paths.py`):
   - `get_app_dir()` — папка .exe (frozen) или корень проекта (dev)
   - `get_data_dir()` — `%APPDATA%/AstroProcessor` (профили, настройки, логи)
   - `get_ephe_dir()` — эфемериды (встроенные в сборку или рядом с .exe)

2. **PyInstaller spec:**
   - Включить `ephe/` как data files
   - Включить `data/cities.json`
   - Hidden imports: `pyswisseph`, `zoneinfo`, `tzdata`
   - Исключить тесты, `__pycache__`, `.git`

3. **Inno Setup скрипт:**
   - Установка в `Program Files/AstroProcessor`
   - Ярлыки (Start Menu, Desktop)
   - Ассоциация `.astro` файлов (опционально)
   - Деинсталлятор
   - Проверка прав администратора

4. **Проверка на чистой машине** (ВМ или мамин компьютер):
   - Установка → запуск → расчёт карты → сохранение профиля → транзиты → прогрессии

## Критерии «Готово к продаже» (Definition of Done v1.0)

1. **Установка:** Inno Setup мастер, установка на чистый Windows 10/11 за < 2 мин
2. **Запуск:** Двойной клик по ярлыку → окно приложения за < 3 сек
3. **Работа без интернета:** Все расчёты, города, эфемериды локально
4. **Паритет функций:** Всё, что было в Streamlit, работает в PyQt
5. **Профили:** Сохраняются в `%APPDATA%`, переносятся между компьютерами
6. **Кастомизация:** Полный контроль объектов/аспектов/орбов/цветов/размеров
7. **Тесты:** 126+ тестов проходят в CI (GitHub Actions)
8. **Документация:** README + USER_GUIDE.md (для мамы) + DEVELOPER_GUIDE.md
9. **Версионирование:** SemVer, changelog, теги в git
10. **Подпись кода (опционально):** Code signing сертификат для убрать предупреждения антивируса
