## 1. Цель продукта

**Одно предложение:**
Локальный профессиональный астрологический процессор для расчёта натальных карт,
транзитов и прогрессий с гибкой кастомизацией, работающий как обычная покупная программа.

**Подробно:**
Продукт рассчитывает карты на основе Swiss Ephemeris полностью локально,
без интернета. Поддерживает натальные карты, транзиты (3 режима), прогрессии
(вторичные и солнечная дуга), графические SVG-карты, профили рождения.
Целевой уровень функциональности — не ниже Zet9 и Skyworker, с перспективой
превосходства за счёт гибкой настройки под себя.

**Что изменится, когда продукт заработает в финальном виде:**

- Запуск двойным кликом по иконке, без терминала и браузера.
- Установка на любой компьютер с Windows через мастер установки.
- Полный контроль над тем, какие объекты, аспекты, орбы и цвета используются.

## 2. Пользователь

- **Основной пользователь:** Сергей (владелец проекта).
- **Дополнительный пользователь:** мама Сергея (другой город) — получит

- **Частота использования:** регулярно, по запросу.
- **Типичный сценарий:** построить натальную карту, посмотреть транзиты

- **Уровень технической подготовки:** пользователь уверенно пользуется
  компьютером, но не программист. Интерфейс должен быть понятен без обучения.

---

## 3. Проблема

**Сейчас:** используются чужие астропрограммы (ориентиры — Zet9, Skyworker),
в которых нельзя настроить всё под себя; собственный проект запускается
через терминал и не готов для передачи другим людям.

**Что в этом плохо:** ограниченная кастомизация в чужих программах;
«разработческий» способ запуска; невозможность установить программу маме.

**Хочу получить:** собственный астропроцессор, который неотличим от покупной
программы: окно приложения, иконка, установщик, работа на чужом компьютере.

## 4. Критерии успеха

- [ ] Программа запускается как обычное приложение (иконка, собственное окно,
      без терминала и браузера).
- [ ] Программа устанавливается на чистый компьютер с Windows без Python
      через мастер установки (Inno Setup).
- [ ] На мамином компьютере работает точно так же, как у владельца,
      включая расчёты (файлы эфемерид) и сохранение профилей.
- [ ] Пользователь может включать/исключать планеты, точки и аспекты
      из расчётов и отображения, менять орбы, цвета, размеры, режим подписей.
- [ ] Расчётная точность сохранена (Swiss Ephemeris, тесты проходят).

## 9. Данные

- **Источники:** файлы эфемерид Swiss Ephemeris (папка `ephe/`), база городов
  (`data/cities.json`), вводимые пользователем данные рождения.
- **Формат:** бинарные `.se1` (эфемериды), JSON (города, профили, результаты).
- **Хранение профилей:** папка `profiles/`, один JSON-файл на профиль.
- **Хранение профилей отображения:** папка `config/display_profiles/`.
- **Известные проблемы качества:** база городов ограничена (~100 записей).
