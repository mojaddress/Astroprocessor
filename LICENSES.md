# Лицензионные заметки Astro Processor

Внимание: это справочная заметка, не юридическая консультация.
Перед коммерческим распространением проверьте актуальные условия лицензий.

| Компонент | Лицензия | Последствия для продажи |
| --- | --- | --- |
| Python | PSF | свободно |
| PyQt6 (Qt) | GPL v3 / коммерческая | закрытое распространение требует коммерческой лицензии Qt |
| Swiss Ephemeris (pyswisseph) | AGPL v3 / коммерческая (Astrodienst) | закрытое распространение требует коммерческой лицензии; либо публикация продукта под AGPL |
| pytest | MIT | свободно (dev-зависимость) |
| platformdirs | MIT | свободно |
| python-dotenv (если используется) | BSD-3 | свободно |
| PyInstaller | GPL с исключением | разрешает бандлинг закрытых приложений |
| Inno Setup | свободная | свободно |

## Вывод
1. Для личного использования ограничений нет.
2. Для продажи закрытого ПО: приобрести коммерческие лицензии Qt и Swiss Ephemeris
   либо распространять продукт под GPL/AGPL с открытым кодом.
3. Альтернатива: заменить PyQt6 на PySide6 (LGPL) — динамическое связывание допускает
   закрытое распространение без коммерческой лицензии Qt (решение отложено, D-55).
4. Данные пользователей (профили рождения) хранятся локально и наружу не отправляются.
