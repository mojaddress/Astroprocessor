# Astro Processor

Локальный астропроцессор для Windows: натальные карты, транзиты, прогрессии,
дирекции солнечной дуги, солнечные обращения (соляры), синастрия, анализ и
встроенная База Знаний. Расчёты — Swiss Ephemeris, полностью офлайн.

## Возможности
- Натальная карта: планеты, дома (Placidus и др.), аспекты, ретро-метки, углы ASC/MC/DSC/IC
- Транзиты: таблица, точные моменты, периоды активности, «Транзиты дня», двухкруговая карта
- Прогрессии: вторичные и солнечная дуга
- Дирекции солнечной дуги: дуга, дирекционные планеты, аспекты к наталу
- Соляры: момент обращения (точность ~1 мин), карта года, город возврата
- Синастрия: межкартовые аспекты, баллы, процент совместимости
- Анализ: локальная интерпретация + опциональное LLM-обогащение (.env)
- База Знаний: 55+ статей, живой поиск, глоссарий, справка из карты кликом
- Экспорт: PNG карты, JSON-отчёты, HTML-портфель (все карты в одном файле для e-mail)
- Профили рождения и профили отображения; живые галочки подписей

## Быстрый старт (Windows)
1. Python 3.11: https://www.python.org/downloads/
2. Зависимости: `py -3.11 -m pip install -r requirements.txt`
3. Запуск: `py -3.11 -m ui_qt.app_qt`
Файлы эфемерид лежат в папке `ephe/` и не требуют интернета.

## Первый расчёт
Профили → данные рождения → город → «Рассчитать карту».
Вкладки справа: Транзиты, Прогрессии, Синастрия, Транзиты дня, Анализ, Дирекции, Обращения.
Меню «База знаний» (F1) — справки; клик по планете/аспекту/знаку на карте открывает статью.

## Экспорт портфеля
Файл → «Экспорт портфеля (HTML)…» — один самодостаточный файл со всеми рассчитанными
картами, таблицами и сводками; готов к отправке по электронной почте.

## Тесты
`py -3.11 -m pytest tests -q` — текущий статус: 171 passed.

## Конфигурация
- `config/default_settings.json` — настройки по умолчанию
- `.env` (из `.env.example`) — опциональная LLM; без ключа продукт полностью локальный
- Секреты в коде не хранятся

## Структура
- `astro_core/` — расчётное ядро (эфемериды, карты, транзиты, дирекции, соляры, БЗ)
- `ui_qt/` — интерфейс PyQt6 (окно, панели, векторная карта)
- `tests/` — pytest-тесты ядра и smoke-тесты UI
- `installer/` — сборка установщика (Inno Setup)
- `data/cities.json` — база городов с координатами и часовыми поясами

## Ограничения
- Даты знаков в Базе Знаний: ±1 день (тропический зодиак)
- Дома соляра зависят от выбранного города возврата (это суть техники)
- LLM-разбор экспериментален и помечен как не гарантия

## Лицензии и предупреждение
См. `LICENSES.md`. Для коммерческого распространения закрытого ПО требуются
коммерческие лицензии Qt и Swiss Ephemeris либо выбор открытых лицензий.

Дисклеймер: продукт предоставляет символические трактовки астрономических расчётов
и не даёт медицинских, финансовых или иных гарантий.
