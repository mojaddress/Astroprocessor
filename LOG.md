# Журнал разработки Astro Processor

## Проект

Локальный модульный астрологический процессор для личного использования.

## Долгосрочная цель

Создать профессиональный, модульный, точный и развиваемый астрологический продукт:

1. Натальные карты.
2. Аспекты.
3. Транзиты.
4. Прогрессии.
5. Интерпретации по базе знаний.
6. LLM-ассистент в строгом режиме.
7. Позже — дополнительные исследовательские модули.

## Stage 01 — Natal Chart Core (версия 0.2.0, модульная)

**Статус:** завершён.

### Что сделано

1. Создана модульная архитектура:
   - `astro_core/constants.py` — константы и настройки по умолчанию;
   - `astro_core/utils.py` — вспомогательные функции;
   - `astro_core/time_service.py` — время и Julian Day;
   - `astro_core/points.py` — Part of Fortune;
   - `astro_core/aspects.py` — расчёт аспектов;
   - `astro_core/ephemeris.py` — адаптер Swiss Ephemeris;
   - `astro_core/chart.py` — сборка натальной карты;
   - `run.py` — входной файл программы.

2. Подключена библиотека Swiss Ephemeris (`pyswisseph`).

3. Реализована поддержка:
   - тропического зодиака;
   - системы домов Placidus;
   - Mean/True лунных узлов;
   - Хирона;
   - Part of Fortune;
   - мажорных аспектов;
   - настраиваемых орбов.

4. Добавлены unit-тесты для ключевых модулей.

5. Создана проектная документация:
   - `README.md`
   - `LOG.md`
   - `requirements.txt`
   - `config/default_settings.json`

6. Проверено:
   - расчёт демо-карты;
   - подключение файлов эфемерид из папки `ephe`;
   - работа с Python 3.11.

### Ограничения Stage 01

- Часовой пояс и UTC offset вводятся вручную.
- Поиск города не реализован.
- Поддерживается только tropical zodiac.
- Part of Fortune использует упрощённую логику day/night.
- Нет веб-интерфейса.
- Нет транзитов и прогрессий.
- Нет интерпретаций.

### Риски, учтённые на этом этапе

- Python 3.14 не подошёл, установлен Python 3.11 рядом.
- Swiss Ephemeris требует корректной структуры возвращаемых данных (исправлена обработка кортежа).
- Разные версии pyswisseph имеют разные API для set_ephe_path (реализована универсальная проверка).

- Резервное копирование: достаточно скопировать папку `profiles/`.
