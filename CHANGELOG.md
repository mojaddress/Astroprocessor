# Changelog

Все значимые изменения проекта документируются в этом файле в формате [Keep a Changelog](https://keepachangelog.com/).

## [1.1.0] - 2026-11-18

### Добавлено

- **Системы домов**: 17 систем (Placidus, Koch, Equal, Whole Sign, Porphyry, Regiomontanus, Campanus, Alchabitius, Topocentric, Meridian, Morinus, Krusinski-Pisarski, Carter Polich-Page, APC, Sripati, Equal MC, Equal Aries)
- **Астероиды**: Церера, Паллада, Юнона, Веста с векторными глифами и галочкой управления
- **Вертекс**: точка западного горизонта в прима-вертикали с отдельным глифом
- **Средние точки**: модуль `astro_core/midpoints.py` с планетарными картинами, 90°-дайалом и сортировкой по орбу; вкладка «🔗 Средние точки»
- **День и часы**: восход/закат, лунный день, фаза Луны, планетарные часы (24 часа халдейского порядка); вкладка «🌙 День»
- **Двухрядная полоса вкладок** правой панели с общей горизонтальной прокруткой
- **GUI-менеджер эфемерид** (Настройки → Файлы эфемерид) с фоновой докачкой и сводкой возможностей
- **Подсказка при первом запуске** при неполном наборе файлов эфемерид
- **CI-пайплайн** GitHub Actions: тесты → сборка → верификация swisseph → артефакты
- **Релизный скрипт** `make_release.py` с чек-листом и защитой от случайной сборки с эфемеридами

### Изменено

- **Ползунок времени**: одна строка управления + строка ползунка; минимум центральной секции 440 px
- **Левая панель**: сетки галочек в две колонки, группа «Подписи и линии» отдельной секцией, минимум ≤ 330 px
- **ASC/MC/DSC**: всегда отображаются на всех картах; галочки убраны из интерфейса
- **Галочки объектов** (Крест, Лилит, Селена, Прозерпина, Астероиды, Вертекс) управляют наличием объектов и их аспектов, а не только подписями
- **Профили отображения**: ключи `Asteroids` и `Vertex` как opt-in объекты (по умолчанию выключены)
- **Упаковка**: hidden import `swisseph` (не `pyswisseph`), пост-проверка наличия модуля в сборке
- **Сохранение профилей**: `created_at` переживает пересохранения, берётся из существующего файла

### Исправлено

- **Регрессия натальной карты**: `set_anchor` ползунка больше не переключает вид на транзиты после расчёта натала
- **Молчаливая деградация**: сборка без `swisseph` теперь блокируется релизным скриптом, а не проходит молча
- **Схлопывание левой панели**: минимумы секций 260/440/300, запрет схлопывания крайних
- **Обрезка левой панели**: горизонтальная прокрутка `AsNeeded` вместо `AlwaysOff`, минимумы кнопок/комбо сняты
- **Флак-тест `created_at`**: устранён продуктовый дефект перезаписи даты создания
- **Abort в test_tab_strip.py**: autouse-фикстура QApplication, таймаут защиты 5 с

### Безопасность

- Лицензированные файлы Swiss Ephemeris (AGPL-3.0) не входят в публичную сборку (`ASTRO_BUNDLE_EPHE=0`)
- Пользователь получает эфемериды отдельно через GUI-менеджер или `fetch_ephe.py`

### Тестирование

- 417 тестов (было 327 в начале сессии)
- Интеграционные тесты UI без `MainWindow.show()` для устойчивости в offscreen-режиме
- Тесты верификации сборки: наличие `swisseph` в dist

### Документация

- Добавлены `ARCHITECTURE_[name].md`, `PROJECT_MAP.md`, `PROJECT_SPEC.md`
- Обновлены `LOG.md`, `DECISIONS_LOG.md` с матрицей превосходства и статусами гипотез

## [1.0.0] - 2026-11-15

Первый стабильный релиз Astro Processor.

### Возможности

- Натальная карта с 10 планетами, Хироном, Лунными Узлами, Фортуной, Крестом Судьбы, Лилит, Селеной, Прозерпиной
- Транзиты, дирекции, соляр, синастрия
- SVG-экспорт карты
- Профили отображения
- База городов с часовыми поясами
- Интерпретации аспектов

### Технические детали

- Python 3.11, PyQt6, Swiss Ephemeris
- 327 тестов
- Модульная архитектура: ядро, контроллеры, UI
